## 二、闭环终态约定

| 决策 | 初始状态 | 终态（经审批/执行回写） |
|---|---|---|
| allow / warn | PENDING_EXECUTION | EXECUTED / EXECUTION_ERROR / NOT_EXECUTED |
| review | PENDING_APPROVAL | approve→EXECUTED（以执行上报为准）；deny→NOT_EXECUTED |
| block / kill | NOT_EXECUTED | NOT_EXECUTED（工具不执行） |

## 三、Golden Path（最小攻击链）

```
读取 客户资料.xlsx → REVIEW(0.595 HIGH) → 人工通过 → EXECUTED
   → 上传 客户资料.xlsx 到外部 → kill(0.85 CRITICAL) → NOT_EXECUTED
行为信号：HIGH_RISK_DATA_EXFIL_CHAIN
事件链：asset_resolved(10) → data_classified(15) → [decoy_virtual_hit(20)]
        → behavior_chain(90) → approval_outcome(100) → execution_outcome(110)
```
